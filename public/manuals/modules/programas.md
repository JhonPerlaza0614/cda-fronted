# Programas académicos

## Buscar
Escribe código o nombre. Ejemplos:
- Código: `2839-DIU`
- Nombre: `Administración de Empresas`

## Crear facultad
1. Selecciona **Nueva Facultad**.
2. Escribe el nombre obligatorio.
3. Opcional: escribe una descripción.
4. Confirma.

Ejemplo:
- Nombre: `Facultad de Ingeniería y Administración`
- Descripción: `Programas académicos y administrativos`

## Crear programa
1. Selecciona **Nuevo Programa**.
2. Código obligatorio al crear. Puede contener guion para jornada, por ejemplo `2839-DIU`.
3. Nombre obligatorio.
4. Número de resolución obligatorio, máximo 15 caracteres.
5. Semestres: entero entre 1 y 20.
6. Facultad opcional.
7. Apertura opcional.
8. Guarda y confirma.

Ejemplo válido:
- Código: `2839-DIU`
- Nombre: `Administración de Empresas`
- Resolución: `Res. 016-2026`
- Semestres: `10`
- Jornada: definida por el código o dato institucional asociado

## Editar
1. Usa el lápiz del programa.
2. Modifica nombre, resolución, facultad, apertura o semestres.
3. El código del programa no debe cambiarse si ya participa en pensums o cursos.
4. Guarda y verifica el resumen.

## Abrir malla
Selecciona **Ver Malla Curricular**. El sistema abrirá el pensum del código seleccionado.

## Desactivar
1. Selecciona el icono de eliminar.
2. Confirma.
3. El programa se conserva como inactivo y sus mallas e históricos no se borran.
