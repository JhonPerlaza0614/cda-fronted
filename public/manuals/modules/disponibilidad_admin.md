# Disponibilidad administrativa

## Entrada
Abre este módulo desde **Plantilla**:
1. Busca el docente.
2. Selecciona sus acciones.
3. Selecciona **Registrar disponibilidad**.

El encabezado debe mostrar el nombre del docente; si no coincide, usa el botón para volver y selecciona otro perfil.

## Registro
1. Confirma el período vigente.
2. Verifica el plazo docente.
3. Selecciona bloques de lunes a sábado.
4. Forma intervalos continuos de al menos 1 hora.
5. No uses sábado después de las `19:00`.
6. Guarda y espera la confirmación.
7. Usa **Volver** para regresar a la plantilla.

Ejemplo válido:
- Docente: `Juan Carlos Gómez Pérez`
- Día: `Martes`
- Horario: `08:00 – 10:00`

Ejemplo inválido:
- `Sábado 19:00 – 21:00`
