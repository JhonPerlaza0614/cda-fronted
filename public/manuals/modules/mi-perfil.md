# Mi perfil

## Datos mostrados
- Nombre completo.
- Correo institucional.
- Rol.
- Estado activo.
- Datos docentes o coordinadores, si corresponden.

## Docente
Datos editables:
- Facultad.
- Correo personal.
- Teléfono.
- Celular.

Datos protegidos:
- Nombre.
- Apellidos.
- Correo institucional.
- Número de documento.

Ejemplo válido:
- Facultad: `Facultad de Ingeniería`
- Correo personal: `juan.gomez@gmail.com`
- Teléfono: `6021234567`
- Celular: `3151234567`

## Flujo
1. Abre **Mi perfil**.
2. Selecciona **Editar**.
3. Cambia únicamente los datos permitidos.
4. Guarda.
5. Confirma con el modal.
6. Verifica que el perfil muestre los nuevos datos.

Si intentas guardar sin cambios, el sistema informará `No hay cambios para guardar`.
