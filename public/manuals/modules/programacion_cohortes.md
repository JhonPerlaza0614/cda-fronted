# Programación y cohortes

## Preparación
1. Confirma que exista un período vigente.
2. Selecciona el programa.
3. Selecciona la cohorte.
4. Revisa la jornada: `DIURNA`, `NOCTURNA` o `AMBAS`.

## Consulta
La información puede mostrar:
- Cursos programados.
- Número de grupo.
- Cupos disponibles.
- Cupos ocupados.
- Estado del curso.

Ejemplo válido:
- Periodo: `2026-2`
- Programa: `2839-DIU`
- Grupo: `53`
- Curso: `751001C - Cálculo I`
- Cupos: `40 disponibles / 40 capacidad`

## Modificar
1. Selecciona el curso que vas a ajustar.
2. Cambia los datos disponibles.
3. Revisa que el cupo no sea negativo.
4. Confirma la operación.
5. Consulta nuevamente el listado para verificar el cambio.

Si no aparecen cohortes, primero debes tener períodos y oferta académica configurados. Solicita al administrador la configuración institucional necesaria.
